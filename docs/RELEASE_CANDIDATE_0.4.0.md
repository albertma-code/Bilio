# Bilio 0.4.0 验收摘要

日期：2026-10-19。状态：macOS Apple Silicon 本机候选版，不是成熟 1.0 或已公证公开安装包。

本摘要不含账号、真实测试来源、媒体文件名或个人路径。完整本机记录不随源码公开。本轮同步源码和说明，不发布安装包。

## 主要变化

- 石墨灰主操作与少量珊瑚红细节，下载库、侧面板及最小窗口交互统一。
- 官方扫码为主入口，可选系统钥匙串保持登录；默认仅本次使用，启动重新验证，任务恢复校验账号身份。
- 暂停/继续、独立工作目录、并发 1–3、批次与多选管理、分集范围和失败项重试。
- 同名保留/校验复用/确认替换，空间与写入检查，媒体验证后发布，更换失败任务目录。
- 数据库 schema 2、升级备份、单条损坏记录隔离、记录/临时文件/最终视频分开处理。
- CSP、登录窗口调用隔离、脱敏诊断预览/导出，以及不自动安装的版本检查。

## 原生安装版证据

- 旧数据库从 schema 1 升级到 2，完成记录恢复并保留升级前备份。
- 官方扫码验证会员状态；确认保存后完全退出，重开无需扫码并重新验证。
- 仅本次使用未保存，重开为未登录；退出本机账号后也不自动恢复。最后由用户亲自恢复日常保持登录。
- 授权番剧 8 集均解析出时长、最高 4K 和 3840×1632，不推广为所有内容可用。
- 新 4K 输出为 3840×1632、AV1/AAC；新 1080P 为 1920×816、H.264/AAC。两个完整文件均通过全程音视频解码。
- 真实暂停后临时文件停止增长，重开仍暂停；显式继续保留任务、目录、策略和断点，最终完成。
- 三轮受控异常退出后未观察到遗留捆绑进程；重开标为中断，不自动重放，同账号显式继续后完成。
- Cmd+Q 确认在验收中发现问题，修复原生菜单后重测通过；窗口关闭也提示，选择继续后仍下载。
- 原生诊断预览与导出已检查，无账号、凭据、标题、来源或个人路径。
- 更新检查遇到 GitHub 匿名 API 限流（HTTP 403），失败不替换应用。正常取得 Release 的原生路径仍未通过本轮验收。

## 保留限制

- 仅一台 Apple Silicon Mac，没有第二环境、Intel Mac、其他系统或外部试用验收。
- 真实来源限定在授权番剧；普通视频、分 P、合集及短链等未完成真实验收，12 个来源/类型样本和 20 次真实成功下载门槛未达到。
- 真实过期、钥匙串拒绝/锁定、换账号、站点权限变化与不同文件系统仍缺完整原生验证。
- 下载依赖可安全硬链接发布的目录，不能宣称所有外置盘格式兼容；AV1 不保证所有播放器兼容。
- 没有 Developer ID 和公证，正式签名身份下的升级与钥匙串访问未验证。
- 捆绑依赖再分发许可审计未完成，见 [第三方组件说明](THIRD_PARTY_NOTICES.md)。

本机核心流程已有可用证据，不把未覆盖项称为已知必现 bug，也不承诺所有场景无 bug。后续以短回归和实际使用中的针对性修复为主。
